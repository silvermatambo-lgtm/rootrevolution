# Root Revolution — WebDevPro Ultra Max 5 Rebrand

Vercel-ready React + Vite website rebuilt from the WebDevPro Ultra Max 5 Master Template.

## Run locally
npm install
npm run dev

## Build
npm run build

## Deploy to Vercel
Import the GitHub repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Project content
- Root Revolution branding and logo
- Product catalogue using supplied product images
- WhatsApp ordering (+27 62 404 2155)
- Our Story, testimonials, FAQ, gallery and contact pages
- PWA install prompt and mobile bottom menu
- WebDevPro footer credit
